Hanoot Platform · Phase J · staff-first

Scan & Go — build the cart on a phone, pay at the cashier

A phone-first app where a staff member scans barcodes (or searches by name) to build a customer's cart, live-validated against stock, then sends it to the cashier by a short code / QR. The cashier pulls the cart, takes cash, and stock decrements — reusing the existing POS + WMS loop. Rolls out to staff first; customer self-scan is a later phase.

Cart = server state. The code is just a pointer — locks on send, can't be edited after. Stock: validate on scan · soft-hold on send · decrement at the cashier (cash collected there). Money authority = cashier.

Mockup notes — Static visual mockup for approval (not wired). Staff-first Scan & Go: PIN login (staff) → scan to build a cart with a live total → live stock check (out-of-stock items are rejected, never added) → search-by-name for no-barcode items (weight-priced → "weigh at counter") → review/adjust → send to cashier (cart locks server-side, shows a QR + short code) → cashier (POS) loads by code, weighs loose items, takes cash → WMS decrements. Reuses the Hanoot POS tokens (ivory/gold/emerald, Manrope + JetBrains Mono) and the D-1/D-2 cashier + WMS loop. Deferred: customer/visitor self-scan, in-app self-payment, offline cache, loyalty capture.

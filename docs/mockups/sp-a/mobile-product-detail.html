Details panel (NEW in SP-A)
Renders core_fields from the schema. Header says "Details" — same label for every section (food / fashion / electronics / etc.). Customer never sees the taxonomy path. Field TYPE drives rendering (chips for arrays, dropdowns for enums). Per-item prep time NOT shown.
Same component, any industry
This identical DetailsPanel renders for t-shirts (size/material/fit), smartwatches (brand/storage/band), etc. Only the schema's fields differ. No industry-specific UI code.
Cart access (Amazon pattern)

Custom fields panel

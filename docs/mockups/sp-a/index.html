HHanoot — SP-A Mockups

Visual mockups for the Catalog + Product-Category sub-project — v2.1. Tap a card to open the mockup. These are static HTML — no real backend.

What changed in v2.1 vs v2:
  • "Specs" renamed to "Details" globally (food-friendly + works for all sections)
  • Sticky cart pill (Talabat / Toters / Uber Eats pattern) — pops up from bottom when items added. Brand-teal pill with badge + total + "View cart". Sticky across screens.
  • Cart icon top-right on product detail (Amazon pattern) with saffron count badge
  • Same cart pill applied to search screen (was missing before)

v2 changes preserved: no per-item prep time, no taxonomy path visible to customer, 2-level default cascade with sub-category toggle, filter chips on search.

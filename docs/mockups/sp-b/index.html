HSP-B Cart & Checkout

Mockups for the cart UX rebuild. Open each in a browser to review. Brand-teal primary, saffron accents — same look as SP-A.

How to give feedback: Look at each mockup, screenshot anything to redirect. Tell me things like "cart row needs bigger image" / "address picker should default to last-used" / "success screen needs phone number for SMS". We iterate to "approved" before any code is written.
Fly-to-cart animation (can't easily mock as static HTML — here's the sequence):
  1. Customer taps + on a product card
  2. A ghost copy of the product image appears at the tapped card position
  3. The ghost scales to 60%, then animates along a curve toward the cart FAB (bottom-right corner)
  4. On landing: ghost scales to 0, FAB does a small bounce (110% → 100%), saffron badge increments
  5. Total time ~400ms. Cubic-bezier(0.34, 1.56, 0.64, 1) curve — slight overshoot for satisfying feel
Reference: Talabat, Shein, Amazon mobile.
